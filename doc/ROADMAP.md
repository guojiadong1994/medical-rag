# Roadmap

## Phase 0
工程骨架、Patient Schema、合成患者数据基线。

## Phase 1
多源文档解析：PDF / DOCX / XLSX / CSV / OCR / Table / Image。

## Phase 2
基础 RAG：Chunk / Embedding / Milvus / Dense Retrieval / Citation。

## Phase 3
Hybrid RAG：BM25 / Dense / RRF / Reranker / Query Rewrite / Metadata Filter。

## Phase 4
Patient-Centric RAG：Timeline / Temporal Query / Cross-document Retrieval。

## Phase 5
Multimodal RAG：OCT / UBM 图文报告、VLM Caption、Image Evidence。

## Phase 6
Ontology / GraphRAG：实体、关系、Neo4j、Graph Retrieval。

## Phase 7
Evaluation：Retrieval / Generation / Citation / Multimodal Metrics。

## Phase 8
生产工程化：RBAC / Audit / Async / Cache / Observability / Docker。

## Phase 9
本地模型：vLLM、并发、TTFT、TPOT、GPU Benchmark。
