# V1.0 完整产品恢复说明

## 为什么有这一版

前一版成品冲刺包只包含了后端与零构建演示页面，没有把历史 `apps/web/` 前端一起放入“完整替换包”。对于采用整目录替换开发方式的项目，这会导致旧前端被误认为已经包含在新包中。

V1.0 完整恢复版重新以仓库原有“智护医疗”前端为产品入口，恢复登录、首页、健康档案、医疗记录、AI 健康助手、设置和知识库管理页面，并把当前真实 RAG 后端接到原来的 AI 健康助手中。

## 本次恢复原则

1. 原前端视觉结构和页面不删减。
2. 已完成的 RAG 后端能力全部保留。
3. AI 健康助手从模拟答案切换成真实知识库请求。
4. 管理员知识库页保留原设计，同时接入真实 PDF 上传接口。
5. 个人健康和医疗记录当前仍属于产品演示数据，因为患者真实时间线尚未实现；界面保留，但文档中明确说明边界。
6. 提供安全恢复脚本，永远不删除 `.env`、`.git` 和已有 `data/`。

## 当前产品入口

真正的产品界面是：

```text
apps/web/
```

运行：

```bash
cd apps/web
npm install
npm run dev
```

浏览器访问 `http://127.0.0.1:5173`。

后端 `python run.py` 运行在 `http://127.0.0.1:8000`。
