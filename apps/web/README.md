# 智护医疗前端

这是项目原有产品界面的恢复与接入版本，保留原有的深青绿色视觉设计、个人健康中心、医疗记录、AI 健康助手、设置和管理员知识库页面。

## 技术组成

- Vue 3：网页前端框架。
- TypeScript：带类型检查的 JavaScript，用于减少前端代码中的类型错误。
- Vite：前端开发与构建工具。
- Vue Router：页面路由管理工具。
- Pinia：前端状态管理工具。
- Element Plus：Vue 的界面组件库。

## 页面

个人用户：

- 首页
- 我的健康
- 医疗记录
- AI 健康助手
- 设置

管理员：

- 医疗知识库管理

## 启动

后端先在项目根目录运行：

```bash
python run.py
```

前端另开一个终端：

```bash
cd apps/web
npm install
npm run dev
```

浏览器访问：

```text
http://127.0.0.1:5173
```

开发模式下，Vite 会把 `/api` 请求转发给 `http://127.0.0.1:8000` 的后端服务。
